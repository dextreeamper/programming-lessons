# Programming Lessons

This repository contains programming lessons, examples, exercises, and activities for students of **The College of Maasin, Inc.**

The repository covers two programming courses:

## 📘 Object-Oriented Programming (OOP)

Lessons and activities focused on the fundamental concepts of Object-Oriented Programming, including:

- Classes and Objects
- Constructors
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Hands-on Programming Activities

## 📗 Event-Driven Programming (EDP)

Lessons and activities focused on building interactive and event-driven applications using **Python and JavaScript**, including:

- Events and Event Handlers
- Event Listeners
- GUI Programming
- DOM Events
- Callback Functions
- Asynchronous Programming
- APIs and JSON
- Error Handling
- AI-Assisted Development
