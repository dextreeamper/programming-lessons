# Programming Lessons

This repository contains programming lessons, code examples, exercises, laboratory activities, and projects for students of **The College of Maasin, Inc.**

The repository covers four programming courses designed to develop students' skills in software development, system integration, web and mobile application development, and emerging technologies.

## 📘 Object-Oriented Programming (OOP)

Lessons and activities focused on the fundamental concepts of Object-Oriented Programming using **Python and JavaScript**, including:

- Classes and Objects
- Constructors
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Debugging and Error Handling
- Hands-on Programming Activities
- AI-Assisted Development

## 📗 Event-Driven Programming (EDP)

Lessons and activities focused on building interactive and event-driven applications using **Python and JavaScript**, including:

- Events and Event Handlers
- Event Listeners
- GUI Programming
- DOM Events
- Callback Functions
- Promises and Async/Await
- Asynchronous Programming
- APIs and JSON
- Error Handling
- AI-Assisted Development

## 📙 Integrative Programming and Technologies (IPT)

Lessons and activities focused on backend development, system integration, and connecting applications with databases and external services using **Python and JavaScript**, including:

- System Integration and Architecture
- Client-Server Architecture
- HTTP Requests and Responses
- Backend Development
- Node.js and Express.js
- Python and FastAPI
- RESTful API Development
- Route and Query Parameters
- Middleware
- SQL and NoSQL Databases
- CRUD Operations
- Authentication and Authorization
- Third-Party API Integration
- Frontend and Backend Integration
- API Testing and Documentation
- Cloud Deployment
- AI-Assisted Development

## 📕 Applications Development and Emerging Technologies (AD&ET)

Lessons and activities focused on designing, developing, testing, and deploying modern **mobile applications**, including:

- Introduction to Mobile Application Development
- Android Studio and Development Environment
- Native and Cross-Platform Development
- React Native
- Mobile UI/UX Design
- Components and State Management
- Navigation and Screen Management
- Forms and Input Validation
- Mobile Application Architecture
- Backend Integration using FastAPI or Express.js
- Database Integration
- User Authentication
- Device Features and Permissions
- AI Integration and AI-Assisted Development
- Mobile Application Testing and Debugging
- Android Application Build and Release
- Google Play Store Deployment
